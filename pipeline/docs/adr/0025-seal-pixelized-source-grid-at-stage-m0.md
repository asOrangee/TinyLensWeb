# Size and seal the pixelized-source grid at Stage M0

Use the Stage-A posterior-median source centre with an initial Source Grid Footprint of `±0.8 arcsec` and `0.02 arcsec` source pixels. The footprint denotes outer cell edges, so its 80 pixel centres span `±0.79 arcsec`. The fixed enlargement sequence is `±0.8 → ±1.0 → ±1.2 arcsec`, represented in configuration only by `source_grid_level`; the Pipeline Release derives `80×80`, `100×100`, or `120×120` pixels so inconsistent half-width and pixel-count combinations cannot exist.

A persistent Stage-M0 Expert judges only grid sufficiency through a dedicated response contract and reports `grid_sufficient`, `source_bbox_truncation`, or `indeterminate`. Confirmed truncation selects the next predetermined footprint, while indeterminate evidence routes to Human Review with `reason_kind: scientific_uncertainty`. Every enlargement consumes the existing M0 and shared physical-stage retry budgets and repeats the complete M0 regularization calibration. Truncation at the maximum `±1.2 arcsec` footprint routes to Human Review rather than further enlargement.

Each M0 attempt writes one required, authoritative `artifacts/source_grid_spec.json`; promotion makes that attempt's specification the M0-Sealed Source Grid. A dedicated high-resolution `diagnostics/stage_m0_source_grid.png` shows its footprint, boundary pixels, and per-edge flux evidence in addition to the standard five-panel model diagnostic. M0 acceptance seals one source grid for M1–M3. Those stages may route newly visible truncation to Human Review but cannot resize or roll back the grid. This concentrates grid repair before mass sampling while retaining a final safeguard against truncation caused by later mass-model freedom; the physical recipe requires a new Pipeline Release and cannot change an active Lens Run. M0 Grid Enlargement is a dedicated deterministic transition rather than Automatic Parameter Tuning because the reviewer decides scientific sufficiency but does not choose a numerical padding value.

M0 classifies truncation only when a coherent extended brightness distribution continues visibly from the source interior into a clipped footprint edge; edge-flux metrics remain supporting evidence without an automatic threshold. Isolated edge noise and boundary-only pathological solutions do not trigger enlargement, while ambiguous evidence terminates as Scientific Uncertainty. M0 Hard Gate and response-contract failures remain operational failures; exhaustion at `±1.2 arcsec` and any newly visible M1/M3 truncation are scientific blockers. The persistent M0 Expert otherwise follows the same correction, resume, retry, and promotion lifecycle as the other Stage Experts.

Stage A supplies only its posterior-median source centre for grid construction. The former derived effective radius, axis ratio, major-axis effective radius, radius factor, and `2.5 R_e` bounding-box metadata are removed rather than retained as grid diagnostics.

Grid enlargement is always symmetric about the immutable Stage-A centre; shifting, one-sided padding, shrinking, and downstream resizing are forbidden. The root configuration and M0 attempt 0 must use grid level 0. Only preparation from a canonical M0 truncation retry decision may advance the level, and user configuration, agent responses, generic overlays, and other stages have no authority to set it. A mismatch among the accepted Source Grid Specification, Effective Configuration Snapshot, reconstructed array shape, or source-template coordinates is an operational integrity failure and is never repaired by an agent.

M1 and M3 route confirmed new truncation to a scientific-blocker Human Review and ambiguous truncation-versus-pathology evidence to a scientific-uncertainty Human Review; neither stage may enlarge or roll back the grid. Every enlarged M0 review context carries compact immutable lineage for the preceding grid levels, judgments, reasons, edge metrics, and attempt-specific diagnostic paths. Golden and deterministic cases together cover true one-edge truncation, isolated edge noise, boundary-only pathology, successful enlargement, maximum-level truncation, downstream truncation, scientific uncertainty, and inconsistent grid provenance.
